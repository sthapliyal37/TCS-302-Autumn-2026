##  About This Repository

This repository contains the learning resources for **TCS 302 — Data Structures Using C**.
The objective is not only to understand how data structures work, but also to learn:

- how to implement them,
- how to analyse their efficiency,
- how to select an appropriate data structure,
- how to trace algorithms manually,
- and how to apply data structures to solve computational problems.

Students are encouraged to use this repository regularly for lectures, coding practice, assignments, quizzes, and revision.

---

# Course Learning Objectives

By the end of this course, students should be able to:

1. Understand fundamental data structures and Abstract Data Types (ADTs).
2. Analyse algorithms in terms of time and space complexity.
3. Implement linear and non-linear data structures using C.
4. Select appropriate data structures for computational problems.
5. Understand searching, sorting and hashing techniques.
6. Implement trees, graphs, heaps and disjoint-set structures.
7. Analyse and compare alternative data structures and algorithms.
8. Apply data structures to real-world problem-solving.
